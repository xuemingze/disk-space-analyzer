## 📖 5 大核心功能使用教程（手把手实操指南）

### 场景一：C 盘空间透视与一键安全清理（解决 C 盘飘红）

当你发现 C 盘空间告急时，使用本功能可以秒级定位大文件和垃圾文件并安全清理：

```text
【操作流程】：
选择磁盘 ──► 点击「快速扫描」 ──► 查看环形分布与 Top100 ──► 点击「一键清理」
```

1. **选择扫描目标**：打开软件，在主界面顶部直接点击盘符卡片（如 `C:\` 或 `D:\`），或者点击右侧 **“📁 选择路径”** 选定特定大目录；
2. **启动分析**：
   * 点击 **“⚡ 快速扫描”**：秒级流式遍历，实时渲染文件类型环形分布图与空间占用看板；
   * 点击 **“🔍 深度分析”**：提取深层文件元数据与数字签名，生成更为详尽的资产全景清单；
3. **定位大文件与垃圾**：
   * 在 **“Top 100 超大文件”** 列表中，一眼看清是哪个虚拟机镜像、未清理的补丁包或视频缓存吃掉了空间；
   * 在明细列表中查看分类（软件安装包、媒体影音、开发依赖、临时日志等）；
4. **安全清理**：
   * 点击 **“📑 AI 深度分析报告”**，系统会自动出具磁盘健康诊断结论与释放方案；
   * 点击 **“🧹 一键清理”**：系统将已确认为冗余的垃圾安全移入**回收站**。如果手抖误清，在回收站随时可原样还原！

### 场景二：桌面与下载目录智能一键归档（散乱文件秒变整洁）

桌面和 Downloads 文件夹堆了几万个文件？本功能可以将它们分门别类归整到整齐的目录树中：

```text
【操作流程】：
切换「AI文件整理」 ──► 选定杂乱目录 ──► 智能分析规划 ──► 预览/微调 ──► 确认执行
```

1. **进入规整模块**：在左侧主菜单点击 **“🤖 AI 文件整理 (Organizer)”**；
2. **选定待整理文件夹**：点击选择源路径（如 `C:\Users\你的名字\Downloads` 或 `桌面`）；
3. **点击「智能分析与归档规划」**：
   * 系统将扫描所有文件，识别真实用途（例如区分这是“06_办公通讯/钉钉安装包”，还是“01_AI工具/模型权重”，亦或是“发票单据”）；
   * 自动规划清晰的 2~3 级分类子目录；
4. **预览并人工微调（绝不盲目移动）**：
   * 弹出结构化规划确认对话框，清晰呈现每个文件“原来在哪”、“建议搬到哪”；
   * **快捷微调**：如果您对某个文件的归类有自己的想法，直接在第 3 列（规划路径）**鼠标双击**或按 **`F2`** 键就地修改。修改后敲回车，系统会记住您的习惯；
5. **执行归档**：确认无误后点击右下角 **“🚀 开始执行”**，散落的文件瞬间整体有序落位。

### 场景三：重复文件零占空间融合（空间省出几十 G，文件照常能用）

很多时候同一个几十 GB 的设计素材、影音或工具在多个项目里都存了一份。普通查重软件一旦删了其中一份，原先的工作路径就断了。本系统创新引入 **NTFS 硬链接融合**：

```text
【操作流程】：
左侧「文件查重与融合」 ──► 选定文件夹比对 ──► 自动精选主副本 ──► 选择「硬链接融合」 ──► 执行
```

1. **进入查重页面**：在左侧菜单点击 **“🔗 文件查重与融合 (Dedup)”**；
2. **选择查重目录**：添加需要排查的目录（支持多目录跨路径比对），点击 **“下一步”**；
3. **3 级快速哈希扫描**：系统通过“大小初步过滤 ➔ 8KB 快速采样 ➔ 并发全量哈希”三级漏斗，几万个文件几秒内即可精准找出完全相同的文件组；
4. **智能推荐保留主副本**：系统会自动综合“创建时间、修改时间、目录深浅”标记最优主副本；
5. **选择处理方案**：
   * **⭐ 方案二：NTFS 硬链接融合（强烈推荐）**：  
     利用 Windows 底层 NTFS 技术，将两处相同文件指向同一块底层磁盘空间。**物理占用瞬间缩减一半，但两个路径下的文件均完好无损，双击依然正常打开、任何软件调用不受任何影响！**
   * **方案一：安全归档**（将重复的多余文件打包迁移到备份目录）；
   * **方案三：原子隔离清理**（将多余副本送入回收站）。
6. **点击「执行治理」**：立刻释放海量磁盘空间。

### 场景四：大型软件/绿色包跨盘无感搬迁（给 C 盘彻底松绑）

C 盘装了几个十几 GB 的大软件不敢动？手动剪切会导致桌面图标失效、注册表报错、程序打不开。本系统提供全自动化无损搬家：

```text
【操作流程】：
扫描明细表找到软件 ──► 右键选择「跨盘应用迁移」 ──► 选定 D 盘目标 ──► 勾选同步快捷方式 ──► 迁移
```

1. **定位目标软件/工程**：在全景扫描或整理列表中，找到占用巨大的软件目录、独立绿色包或代码项目；
2. **右键发起搬迁**：右击该资产，在弹出的菜单中选择 **“📦 跨盘应用迁移”**；
3. **设置迁移目的地**：
   * 目标路径选择空间充足的磁盘（如 `D:\MigratedApps`）；
   * **勾选“同步更新快捷方式与注册表”**；
4. **一键迁移**：
   * 软件自动将整个目录整体平移到 D 盘；
   * 在原 C 盘位置自动建立 **NTFS 透明目录联接 (Junction)**，Windows 底层和其它程序访问原路径时会自动透明映射到 D 盘；
   * 自动同步更新桌面快捷方式（`.lnk`）、开始菜单入口及注册表关联；
   * **一键回滚保障**：迁移完成后自动生成回滚记录，如果未来想搬回，随时在界面一键原样还原。

## ❓ 常见问题答疑 (FAQ)

#### Q1：使用本软件清理或移动文件安全吗？会不会误删系统文件？
> **答：绝对安全。**  
> 1. 系统内置了严苛的 Windows 系统关键目录白名单（如 `C:\Windows`, `System32`, `WinSxS`, `Program Files` 关键驱动等），涉及系统安全的地方全部做了硬拦截；  
> 2. 所有清理操作默认进入 Windows 回收站；  
> 3. 规划整理均遵循“必须经由用户在预览界面确认才移动”，绝不暗箱操作。

#### Q2：NTFS 硬链接融合到底是什么原理？真的能腾出空间吗？
> **答：这是 Windows NTFS 磁盘文件系统的原生安全特性。**  
> 当两个文件内容 100% 一致时，硬链接将原本占用两份物理磁盘扇区的记录合并指向同一份数据，另一份扇区直接释放给系统。因此空间立刻真实释放，且两个路径的文件各自独立可用，毫无副作用。

#### Q3：跨盘迁移软件后，快捷方式还能打开吗？
> **答：可以完全正常打开。**  
> 迁移引擎会自动创建 NTFS 目录联接（Junction），在操作系统眼中原路径依然完全存在；同时系统会自动同步更新桌面 `.lnk` 快捷方式与注册表对应项，体验完全无感。

#### Q4：运行时产生的日志存放在哪里？
> **答：** 如果遇到异常或想排查运行情况，可在软件运行根目录下的 `logs/` 文件夹中找到日志文件（`app.log`、`error.log` 与崩溃快照日志）。
