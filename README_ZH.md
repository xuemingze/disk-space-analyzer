## 🎯 核心用途与解决的核心痛点

```text
 面对这 5 大常见电脑顽疾，本系统能为您做什么？
 ─────────────────────────────────────────────────────────────────────────────
 1. C 盘常年飘红爆满 ───► 秒级扫描全盘大文件、深层日志与缓存，一键清理无用垃圾
 2. 几万个散落文件卡死 ──► AI 智能理解用途，按工程/工具链/单据一键分门别类收拢
 3. 相同大文件堆积吃硬盘 ─► 零占空间 NTFS 硬链接融合，瞬间省出几十 G，文件照常能开
 4. 软件不敢动怕报错 ───► 大型软件跨盘无损迁移，自动链接并同步桌面快捷方式与注册表
 5. 正在编辑的文件怕被删 ─► 自动化中心独占句柄安全探测，使用中的文件强制保护跳过
```

### 1. 🔍 空间全景透视：揪出吃硬盘的“元凶”
* **秒级流式快照**：告别漫长等待，采用高速流式扫描，瞬间绘制出磁盘占用环形分布图与文件类型排行；
* **Top 100 超大文件清单**：一眼定位隐藏在深处的虚拟机镜像、超大压缩包、冗余安装程序与影音缓存；
* **直观操作安全清理**：内置权威 Windows 保护白名单，精准识别安全可清理项，右键支持一键定位或直推回收站。

### 2. 🤖 AI 智能文件规整：散落文件一键变整洁
* **不只是按后缀分类**：打破死板的“把所有 .exe 或 .zip 扔到一个文件夹”的机械做法；
* **AI 语义理解真实业务**：大模型自主洞察真实用途（如“前端工程”、“数据库工具”、“财务报销单据”、“运维安装包”），自动构筑 2~3 级整齐目录树；
* **支持本地示范目录学习**：指定您习惯的一个整洁示范文件夹（如 `D:\常用工具`），AI 自动汲取建树风格，从此全盘归档与您的习惯一模一样；
* **断网离线引擎无缝保底**：即使断网或未配置大模型，内置高精度本地专家规则库依然毫秒级响应，所有整理功能照常运转。

### 3. 🔗 重复文件零占空间融合：空间省了，文件还在
* **首创 3 级哈希漏斗**：“大小粗筛 + 8KB 快速采样 + 并发全量哈希”，数万文件查重秒级完成；
* **NTFS 硬链接（Hardlink）融合黑科技**：
  * 同盘重复文件合二为一，瞬间释放几十 G 冗余磁盘空间；
  * 原先的各个路径依然保留完全一致的文件快捷入口，双击照样正常打开，既省了空间又完全不打乱平时的工作路径！

### 4. 📦 大型软件/游戏跨盘无损搬家：给 C 盘真正减负
* **NTFS 目录联接（Junction）**：把占用几十 G 的大型软件、独立绿色包安全搬到 D 盘，在原位置建立透明联接；
* **快捷方式与注册表全自动同步**：自动扫描更新桌面、开始菜单快捷方式（`.lnk`）和系统注册表关联路径，搬迁后双击快捷方式软件照样秒开；
* **一键原路逆向回滚**：每次迁移均生成防灾凭据，遇到任何问题随时一键原样复原。

### 5. 🛡️ 自动化中心常驻守护：安全巡检与独占保护
* **文件被占用安全阻断 (In-Use Guard)**：归档或清理前自动检测文件独占句柄与进程依赖，正在使用的文档、正在运行的代码或程序强制跳过，杜绝文件损坏；
* **静默定时巡检**：设置每周/每日或高磁盘水位自动巡检，保持磁盘长期处于健康清爽状态。

## 🚀 快速上手操作指南

### 场景 1：主控扫描 —— 盘点空间分布与一键清理
1. 打开客户端，在上方盘符卡片选择目标磁盘（如 `C:\` 或 `D:\`），或点击 **“📁 选择路径”** 选定特定目录；
2. 点击 **“⚡ 快速扫描”** 或 **“🔍 深度分析”**，系统秒级输出环形图、空间占用看板与 Top 100 明细表；
3. 点击 **“📑 AI 深度分析报告”** 查看空间健康诊断与治理建议；
4. 点击下方 **“🧹 一键清理”** 执行安全清理。

### 场景 2：文件整理 —— 散落目录 AI 一键智能规整
1. 在左侧导航栏切换至 **“AI 文件整理 (Organizer)”**；
2. 选择待整理的源文件夹（如杂乱的 `Downloads`、`桌面` 或杂乱项目目录）；
3. 点击 **“🤖 智能分析与归档规划”**；
4. 在弹出的规划确认向导中：
   * 预览 10 列结构化目标目录树；
   * 如需微调建议规划路径，直接在第 3 列双击就地修改；
5. 点击 **“🚀 开始执行”**，散落文件瞬间规整到清晰规范的层级目录中。

### 场景 3：重复文件查重 —— 智能识别主副本并无损合并
1. 点击左侧导航栏 **“文件查重与融合 (Dedup)”**；
2. 选定待查重的目标目录，点击 **“下一步”** 开始并发哈希比对；
3. 查看查重报告：系统自动根据“创建时间、修改时间、目录权威层级”帮您精选保留最佳主副本；
4. 选择治理方案：
   * **方案一：安全归档**（打包备份冗余副本）；
   * **方案二：NTFS 硬链接融合（推荐）**（瞬间释放空间，双路径文件依然可用）；
   * **方案三：原子隔离清理**（移入回收站）；
5. 点击 **“执行”** 完成秒级瘦身。

### 场景 4：大型软件/工具链跨盘无感搬迁
1. 在主控扫描明细表格中，选中识别出的独立软件或开发工程；
2. 鼠标右键选择 **“📦 跨盘应用迁移”**；
3. 选择目标盘符（如 `D:\软件与文件迁移`），勾选 **“同步更新快捷方式与注册表”**；
4. 点击 **“开始迁移”**，完成后 C 盘空间立即释放，原有桌面快捷方式照常使用。

## 🛠️ 常见问题 (FAQ) 与故障排查

#### Q1: 软件清理或迁移文件安全吗？会不会误删系统文件？
> **A**: 极度安全。系统内置了严格的 Windows 系统级白名单（`System32`、`WinSxS`、`Program Files` 核心区等受强制保护禁止直接删除）。清理动作默认移入系统回收站，迁移操作支持随时一键原路逆向复原。

#### Q2: 什么是 NTFS 硬链接（Hardlink）融合？真的能省空间吗？
> **A**: 它是 Windows NTFS 文件系统的底层原生特性。两个路径指向磁盘上的同一份物理数据块，不额外占用多余存储；删除其中一个并不影响另一个，真正做到既释放空间、又不打乱用户使用习惯。

#### Q3: 如果遇到软件异常，去哪里找排障日志？
> **A**: 客户端挂载了全局异常拦截保护，所有日志均安全落盘在软件所在目录的 `logs/` 文件夹中（`logs/app.log` 与 `logs/error.log`），随时可用于排查。
