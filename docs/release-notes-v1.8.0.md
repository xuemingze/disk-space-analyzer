# Release Notes - v1.8.0

## 🚀 版本亮点 (Highlights)

本版本专注于**面向对象强类型领域模型与管线解耦**、**AI 多版本文件语义差异比对与保留决策**、**软件安装包与广域容器防御修复**、**大模型生成耗时与超时保护优化**与**工程历史档案规整**：

1. **面向对象强类型领域模型与流式管线重构 (OOP & ScanPipeline Architecture)**：
   - 严格践行面向对象思维，全面落地强类型数据模型 [`ScannedAsset`](file:///d:/项目/空间全景深度分析与冗余文件扫描/app/core/domain_models.py) 与同族多版本聚类模型 [`VersionClusterGroup`](file:///d:/项目/空间全景深度分析与冗余文件扫描/app/core/domain_models.py)；
   - 消除散落 Dict 字典在不同函数与模块间穿梭带来的键名拼写错误与隐式耦合风险；
   - 建立高内聚、职责分明的流式扫描管线 [`ScanPipeline`](file:///d:/项目/空间全景深度分析与冗余文件扫描/app/core/scan_pipeline.py)，将扫描、拓扑识别、属性丰富与原子收拢阶段分层解耦，执行效率显著提升。

2. **AI 多版本文件语义差异比对与智能保留决策系统 (Semantic Version Diff & Retention Decision)**：
   - 研发同族多版本聚类探测器 [`VersionClusterDetector`](file:///d:/项目/空间全景深度分析与冗余文件扫描/app/core/version_cluster.py)，自动识别并聚类具有相同语义主干、不同演化后缀（如 `_v1`、`_v2`、`_最终版`、`_修改版`）的文档与代码；
   - **双视图交互入口**：在主控全景明细表格（`FileDataGridWidget`）及重复治理审查表（`ReviewTableStep`）中无缝集成右键菜单与顶栏【🤖 AI 版本比对】按钮；
   - **独立可视化决策对话框 (`VersionDiffDialog`)**：AI 统揽全局，极速生成版本演进脉络对比表格与保留决策；用户一键采纳即可自动保留最新/关键版本，将其余冗余历史版本归档，并自沉淀治理规则。

3. **软件安装包/下载池（广域容器）误判缺陷彻底修复 (Broad Container & Installer Pool Fix)**：
   - 彻底修复了类似 `D:\安装包`、`D:\下载` 等常见工具池目录被误收拢为“1 个不可拆分的原子实体集体”的痛点缺陷；
   - 建立专有安装包池识别判定 [`is_installer_pool_dir`](file:///d:/项目/空间全景深度分析与冗余文件扫描/app/core/app_detector.py)，剔除粗暴的 `len(exe_files) > 1` 启发式规则；
   - 强化根目录扫描防线与广域容器分类特征，准确将包含独立安装包的目录解析为清晰的单项资产列表。

4. **大模型耗时优化与防雪崩机制 (AI Latency Optimization & Non-Overreach)**：
   - 全面关闭大模型前置长链思考消耗（`thinking: disabled`），直接秒级吐出高质量结构化诊断与规划计划；
   - 为空间健康报告（2500 Tokens）、冗余文件推荐（1500 Tokens）与分类聚合（2000 Tokens）分别设定精确 Token 边界，生成耗时从超过 100 秒骤降至 20~30 秒；
   - 严格恪守“本地不抢功冒进”方针与准则一（AI-First），若遇不可抗力网络中断，通过 `AIDecisionBannerWidget` 忠实呈现事实并提供用户自主定夺入口，严禁静默离线越权覆盖。

5. **工程临时文件彻底清理与《项目全景执行历程》档案建立**：
   - 全面清理仓库根目录下的一次性测试脚本与历史补丁；
   - 建立系统级架构理论与实战档案 `docs/构建核心理论.md` 与《项目全景执行历程与架构演化全貌》，保持项目结构清爽、规范、可追溯。

## 🛠️ Bug 修复与体验调优 (Bug Fixes & Refinements)

- **修复**：软件安装包/下载目录在扫描时被误归纳为单一原子集体的缺陷；
- **修复**：大模型生成报告时因输出过长导致超过 100 秒读取超时（ReadTimeout）并触发重试的问题；
- **优化**：全工程单元测试完全隔离对外部大模型真实网络的依赖，保障离线与 CI 环境执行确定性；
- **优化**：CI/CD 发布流水线测试步由 PowerShell 调整为 CMD 执行，避免 PowerShell 7.4 Stderr 拦截退出码异常。
