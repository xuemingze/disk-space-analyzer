# Release Notes - v1.7.0

## 🚀 版本亮点 (Highlights)

本版本专注于**强化 AI 为核心编排架构与用户决策自主权**、**建议归档规划路径就地编辑高保真微调体验**、**面向对象组件化抽离**与**全局暗色高对比度视觉无障碍重塑**：

1. **AI 核心编排与用户自主决策权（准则一深化落地与不越权原则）**：
   - 彻底修复了大模型请求超时或异常时本地离线兜底直接越权覆盖 AI 输出的体验缺陷，确立 **AI 为核心、用户定夺、绝不越权** 的交互契约；
   - **独立资产 > 100 项架构诊断决策**：当目录扫描后识别出散落独立资产超过 100 项时，系统研判识别出“80% 可能性为集合判断错误”（如应用工程、业务单据、虚拟机/模型角色未收拢为原子实体集体）。自动暂停直接向大模型倾泻成百上千碎片，避免 Prompt 爆炸与超时，并在前端展现统一面向对象的诊断卡片；
   - **全屏最大化明细工作台联动**：推荐选项【🔍 查看全局扫描资产明细 (推荐并最大化)】直接无感切换至全局扫描资产明细并一键全屏最大化，引导用户就地右键「向上收拢转集合」，从根本上解决离散碎片；
   - **强制 AI 总结/整理显式授权**：保留【⚡ 强制 AI 总结 / 强制 AI 整理】选项，由用户自主定夺是否忽略聚集风险立即提交 AI 智能分析，严禁后台未经授权私自调用大模型或静默兜底越权覆盖。

2. **面向对象组件架构抽离 (`AIDecisionBannerWidget`)**：
   - 将诊断与决策卡片封装为面向对象统一独立组件 `AIDecisionBannerWidget`，深度复用于主控全景扫描看板 (`HomeView`) 与 AI 智能文件整理中心 (`OrganizerView`)；
   - 实现了资产明细卡片与决策控制器的组件化、同构路由联动，消除重复代码与脚本割裂。

3. **规划路径就地编辑原路径保全与高保真微调 (In-Place Path Preserving Edit)**：
   - 彻底解决在全景数据表格中双击/F2 修改第 3 列（建议规划路径）时被清空的痛点体验；
   - 研发挂载专有就地编辑委托 `PlanningPathItemDelegate`，打开输入框时 100% 预填并保全既有建议归档路径文本，并默认全选高亮；用户可直接就地在原路径上增删字符或微调分类层级，敲击回车即刻触发极速 AI 审核与知识库自沉淀。

4. **全局高对比度视觉重塑与排版无障碍规范 (High-Contrast UI & Dark Theme Accessibility)**：
   - 遵循用户体验与无障碍规范，彻底禁止表格和树形组件中出现“白底白字”或“黑底黑字”看不清的问题，禁用黑白交替斑马纹造成的视觉干扰；
   - 全局分类拓扑树、组织向导树等核心视觉树全面重构为蓝底亮白字（`#38BDF8`）、绿底亮白字（`#10B981`）与深邃暗底纯亮白文本（`#F8FAFC`），搭配 44px 黄金行高锁定，视觉对比度鲜明、层次分明、极度清晰。

5. **Shiboken6 C++ 对象生命周期与日志安全隔离 (Memory & Lifecycle Hardening)**：
   - 针对 PySide6/Shiboken 窗口或组件销毁后，全局 `app_logger` 挂载的 GUI 日志句柄尝试写入已释放 C++ `QTextEdit` 导致崩溃的边界隐患进行了原子级生命周期判定与自解耦保护，彻底杜绝悬垂日志指针。

## 🛠️ Bug 修复与体验调优 (Bug Fixes & Refinements)

- **修复**：全景明细表格第 3 列就地双击编辑时因 `EditRole` 丢失导致的路径先被清空问题；
- **修复**：大模型生成报告响应超时或失败时前端文本被本地离线报告静默覆盖、篡夺 AI 主编排地位的架构越权缺陷；
- **优化**：文件整理视图与主控扫描视图面向对象同构对齐，共享 `AIDecisionBannerWidget` 与全屏资产明细工作台跳转能力；
- **优化**：分类拓扑树节点渲染颜色优化为深底高亮白字，消除对比度不足与阅读困难。

## 🧪 自动化测试验证 (Testing)

- 自动化测试用例集扩充至 **116 项**，全部通过测试（`116 passed in 17.30s`）：
  - 新增 `PlanningPathItemDelegate` 就地编辑原路径保全与数据模型同步专项测试；
  - 新增 `AIDecisionBannerWidget` 超阈值诊断模式、错误诊断模式与信号投递契约测试；
  - 新增 `HomeView` 独立资产 > 100 项全屏最大化资产明细跳转与强制 AI 总结测试；
  - 新增 `OrganizerView` 独立资产 > 100 项决策横幅与跨视图路由联动测试。
