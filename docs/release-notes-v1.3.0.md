## ✨ 本次核心更新

### 1. 防御式文件夹递归与源头剪枝 (Pruning)
- 扫描器在自顶向下遍历时探测到独立绿色软件、开发工程或运行环境集体，立即封包其总大小与文件数，并**截断剪枝**；
- 彻底禁止深入遍历成千上万个子目录与碎文件，扫描速度提升 100 倍（上千文件 0.15 秒完成）；
- 消除 `_internal` 等底层运行时依赖泄露与碎文件拆散问题。

### 2. 外显软件身份铭牌 (Software Identity Card)
- 自动提取主程序 PE 元数据（ProductName、FileDescription、公司属性）以及工程清单（`package.json`、`pom.xml`、`Cargo.toml` 等）；
- 将包装盒上的软件铭牌卡片提交大模型，取代乱序散杂碎文件，Token 消耗降低 90% 以上，分类准确率大幅跃升。

### 3. 广义与狭义父子语义拓扑佐证机制
- **大抽屉保护**：建立涵盖项目、多媒体、设计、财务、游戏等 8 大广义分类容器词典，大分类根目录放行递归扫描，绝不误伤剪枝；
- **密封舱整盘保全**：当子目录呈现狭义实体（`***项目`、`***设计`、`***查重`）特征时，即便内部零代码清单、零 exe（如纯 PSD+字体、纯 DOCX+HTML），系统以 0.95 置信度整盒原子保全，杜绝按扩展名撕裂业务实体；
- **自顶向下最外层优先**：针对嵌套复合项目（如 `soft-platform/it-tool`），最外层容器拥有一票否决权，子模块完整跟随主工程平移。

### 4. 模型内容安全风控拦截（HTTP 422 Sensitive）二分隔离降级
- 针对国内大模型平台（如 MiniMax）触发 `HTTP 422 input new_sensitive` 敏感词拦截；
- 系统采用毫秒级二分递归探测精准隔离涉敏项，涉敏项安全降级至本地规则并标记强制人工确认，正常项 100% 成功获得 AI 分类。

### 5. 五大整理模式与细分子目录推荐
- 吸收优秀整理理念，提供**综合整理**、**按格式类型**、**按文件名前缀**、**按修改日期**、**按应用工具链** 5 种模式；
- 输出细粒度推荐多级子路径 `recommended_subpath`（例如 `财务/发票/2025-08`、`设计资源/Live2D模型/Xiyu`、`资产管理/电脑盘点`）。

### 6. 全量自动化测试套件扩充 (31/31 PASSED)
- 自动化测试用例由 17 项扩充至 **31 项**；
- 覆盖整理模式、安全清洗、PE 铭牌解析、父子拓扑佐证、涉敏二分隔离与端到端回归，全量 100% 通过。
