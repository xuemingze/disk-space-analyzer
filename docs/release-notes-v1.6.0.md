# Release Notes - v1.6.0

## 🚀 版本亮点 (Highlights)

本版本带来了架构级演进与重磅功能升级，彻底贯通**三大整理原则**，首创**全局资产一改俱改同构收拢体系**与**应用管理一级看板**，并彻底重塑了 **AI 决策与本地归档的执行管线**：

1. **AI 统筹创作与表格直灌入轨 (AI Direct Execution Plan)**：
   - 彻底打破“AI 归 AI 分析、本地跑死板脚本”的两张皮割裂；
   - 全局分类从硬性限制降维为“语义参考基准”，赋能 AI 自主研判并升维提炼出“经控”、“财务单据”、“工程微服务”等高阶业务分类；
   - 一次大模型交互即完成【全景健康报告 + 结构化执行清单】创作，本地 0 延迟秒级将执行清单直灌全域数据表格与整理预览向导。

2. **全局资产一改俱改同构收拢体系 (Unified Collective Promotion)**：
   - 全局扫描资产、重复资产、可释放资产、Top 100 资产全量同构右键菜单；
   - 引入智能父级路径推断单选弹窗 (`PromoteCollectiveDialog`)，点击即可就地收拢碎片为命名集合，全表联动收割并消除内部冗余。

3. **权威注册表拓扑索引与双保险持久化 (Registry App Topology & Dual-Layer Persistence)**：
   - 深入索引 Windows 注册表 `Uninstall` 项，权威掌握本机真实安装的软件安装根目录；
   - 自定义沉淀应用采用双保险独立持久化 (`~/.disk_space_analyzer/custom_apps.json` 与主配置)，软件重启零丢失；
   - 阶段一彻底解除阻塞，秒级完成应用拓扑扫描。

4. **极速流畅性与页面切换性能优化 (High Performance & Zero-Lag)**：
   - 引入扫描会话级集体探测快速缓存与会话级哈希快速通道；
   - 优化 UI 渲染惰性更新，彻底解决扫描时间偏长、页面频繁切换卡顿问题。

5. **AI 5类高价值核心资产前置过滤管道 (Token Efficiency Optimization)**：
   - 对海量小碎片文件实施 0 Token 拦截阻断；
   - 仅将安装包、系统镜像、办公文档、APK、软件集合与关键摘要提交大模型，大幅提升大模型分析速度并节省 Token。

6. **全景资产 AI 智能研判对话框 (AI Insight Dialog)**：
   - 全表右键与应用管理看板均可一键调起 AI 单项资产智能研判；
   - 融合在线大模型研判与本地离线启发式规则引擎保底。

## 🛠️ Bug 修复 (Bug Fixes)

- **修复**：主控扫描后因 Tab 索引硬编码跳转导致 AI 深度报告看不到的界面错位问题；
- **修复**：国内大模型（如 MiniMax-M3、Qwen）直接输出 Markdown 报告文本时被当成非法 JSON 丢弃的兼容性异常；
- **修复**：`PromoteCollectiveDialog` 控件加载时序导致的 `txt_dir` AttributeError 崩溃问题；
- **修复**：`PromoteCollectiveDialog` 缺少 `QWidget` 导入导致的崩溃问题；
- **修复**：文件整理菜单默认打开空的 `Downloads` 文件夹导致提示未扫描到任何文件的体验缺陷，支持智能首选目录探测与路径记忆。
