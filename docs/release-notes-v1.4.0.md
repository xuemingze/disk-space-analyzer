## ✨ 本次核心更新

### 1. 三大整理核心原则全链条贯通 (Three Core Architectural Principles)
- **原则一：防御性递归原则 (Defensive Recursion Principle)**
  - 扫描栈遍历到原子狭义集体时，**源头剪枝汇总封包**，严禁零散碎文件、运行时依赖（`_internal`、Node 依赖、LevelDB 数据块等）泄露入栈；
  - 性能表现卓越：面对 `D:\MovedApps\edge`（11,450 个碎文件）及 `C:\Program Files (x86)`（10,211 个碎文件），2 秒秒级扫描完成，散装碎文件全数归零；
  - 全生命周期原子化保全：从阶段一轻量扫描、阶段二集体哈希比对、阶段三聚合与可释放分析，到 UI 四大表格呈现、智能全选、AI 报告、后台归档平移与永久清理，原子实体集体始终作为**单一高阶资产单元**参与。

- **原则二：泛式大抽屉与狭义实体拓扑法则 (Generic Broad Umbrella vs. Narrow Entity Topology Law)**
  - **边界泛化与一级目录解禁**：仅保留驱动器根与系统大区保护，废除硬编码盘符层级限制，安装在非系统盘根目录的独立软件（如 `D:\Clash`、`D:\Everything`、`D:\图吧工具箱`）自然识别为独立软件集体；
  - **泛式大抽屉上位赋权**：大抽屉词典全面升级（覆盖 `MovedApps`、`backups`、`财务`、`Live2D`、`多媒体` 等）；父子语义落差拓扑前置裁决，大抽屉下属子项强制继承上位语义，快照坚决识别为【历史快照集体】，彻底杜绝被内部清单反客为主识别为活跃代码。

- **原则三：同源同宿——源路径同构保全在全链条的贯通 (Source Umbrella Consistency)**
  - 全链条沿用源泛目录命名结构同构映射推荐子路径（如 `应用软件/MovedApps/edge`、`归档备份/backups/snapshot_...`）；
  - **备份资产免误判保护**：`backup` / `备份` 大抽屉下的压缩归档（如 `.tar.gz`、`.bak`）享有核心历史资产免误判保护，杜绝打上“冗余归档包”标签。

### 2. 全生命周期资产枚举体系全面重构
- **消除散装感**：四大核心资产表格（可释放文件明细、全局明细文件、Top 100 超大资产、全局景深）全面改造为原子实体集体与独立资产单元主导；
- **Top 100 超大资产引入 >300MB 严格门槛**：不再被几十兆甚至几兆的碎片文件填充，只展示真正占用海量空间的重量级资产；
- **资产治理名牌化与专属图标**：表格直观区分 📦 [独立软件]、🗜️ [归档快照]、📂 [业务账套]、🎨 [设计素材]、💻 [工程项目] 等高阶形态，并外显底层聚合文件总数。

### 3. AI 智能整理与诊断报告升级
- 增强报告容错防御机制，兼容动态字段；
- Top 10 超大资产列表自动挂接主程序外显身份铭牌（如 `Application (Microsoft Edge)`、`7 (Microsoft .NET)`），告别冰冷无意义的版本号/目录名。

### 4. 自动化测试套件扩充至 35 项 (35/35 PASSED)
- 新增三大核心原则全流程贯通的集成测试套件；
- 覆盖防御性源头剪枝、泛式大抽屉拓扑赋权、归档资产同源同宿保全与 Scanner 深度集成，全量 100% 通过。
