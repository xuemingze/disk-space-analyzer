# 📖 使用说明与安全须知

> 本文档由项目根目录的《文件清理助手使用说明》整理而来，是**动手清理磁盘前必读**的操作规范。

---

## 一、这个工具解决什么问题

主要是为了清理 C 盘。很多时候 C 盘爆满，可以用它**按文件大小定位占用大户**，再通过归档或迁移把空间腾出来。

---

## 二、下载与启动

| 方式 | 说明 |
| --- | --- |
| **便携版（推荐）** | 下载 `DiskSpaceAnalyzer-*-win64-portable.zip`，解压后双击 `DiskSpaceAnalyzer.exe`，无需安装 Python |
| **单文件版** | 下载 `DiskSpaceAnalyzer-*-win64.exe`，双击即可运行（首次启动稍慢，属正常解压行为） |
| **源码运行** | `pip install -r requirements.txt` 后执行 `python main.py` |

下载入口见 [README](../README_ZH.md#-下载与使用) 或 [Releases 页面](https://github.com/xuemingze/disk-space-analyzer/releases)。

> 💡 程序运行日志、错误日志、崩溃快照会写入 exe 同级的 `logs/` 目录。
> 遇到异常时请把 `logs/error.log` 或 `logs/crash-*.log` 一并反馈，可直接定位问题。

---

## 三、推荐操作流程

1. **选择盘符 / 路径** → 开始扫描，先看「空间全景」与「Top 100 超大文件」。
2. **勾选「保护系统核心目录」**（默认建议保持勾选），防止系统目录被误动。
3. 确认清理方式：
   - **一键归档** —— 移动到归档路径。**推荐优先使用**，确保没问题或几天后用不到再手动删除。
   - **一键清理** —— 直接删除（走回收站）。**请谨慎选择**。
4. 出现异常可在**回滚**页面回滚，**支持部分回滚或全部回滚**。

## 四、关键注意事项

### ⚠️ 清理 C 盘时，一般不要勾选「哈希查重」

哈希查重用于找出重复文件副本，**在清理 C 盘空间的场景下通常不是你要的**：它耗时长，且容易把系统组件之间的正常副本识别为"冗余"。清理 C 盘请以「大文件 / 大目录」为主线。

### ⚠️ 归档前必须核对目标路径

**尽量不要直接「全部归档」**，务必逐项核对后面的目标路径，确认无误再执行。

### ⚠️ 游戏 / 大型软件不建议直接归档

例如游戏在 C 盘占了 33G：**尽量选择卸载游戏后重装到其他盘**，而不是用本工具归档。
原因：这类软件有大量琐碎文件分散在各处，单纯移动目录常导致软件无法启动。若确实要跨盘移动且保持可用，请使用「智能迁移」功能（会创建 NTFS Junction 并同步快捷方式/注册表）。

### ⚠️ 忽略文件夹 = 不扫描路径

例如 C 盘的一些系统文件夹。勾选「系统不扫描」后，`system` 相关目录默认不扫描。

## 五、AI 能力（可选）

- 在**配置**中填入大模型 API（支持 OpenAI / DeepSeek / MiniMax / Qwen / 本地 Ollama 等任意 OpenAI 兼容端点），以及归档路径、忽略文件夹。
- 配置完成后，扫描结束会自动生成 AI 总结，帮助你判断哪些内容可以清理，并可导出 Markdown 文档参考。
- **文件整理**用于辅助 AI 自动分类。AI 不会认识所有软件，因此大部分只会列出结果，**需要你在结果中自行编辑分类**。
- 文件越多耗时越长，**尽量不要一次性对一整个几十 G 的盘做文件整理**。

> 未配置 API Key 时，程序会自动回退到内置离线规则引擎，功能仍可用。

---

## 六、遇到问题怎么办

1. 打开 exe 同级 `logs/` 目录。
2. 取 `error.log`（错误明细）或 `crash-*.log`（未捕获异常完整堆栈）。
3. 提交 Issue 时附上日志与复现步骤。
